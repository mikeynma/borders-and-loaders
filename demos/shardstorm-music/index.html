The tune while it loads

Shardstorm's AY tune plays the whole time its 128K tape loads, at the ROM's normal speed, from a plain .tap.

Music while a game loads, as some 1980s loaders did - but our own loader, and Shardstorm's own tune. It plays from the first block after the loader to the game's menu.

How it works

A register an edge

The loader times the tape's pulses by counting round a short loop. Every time it sees an edge, it spends exactly 196 T-states writing one of the AY's registers - always the same time, so its measurements can allow for it. An interrupt fifty times a second moves on to the next frame of the tune. With an edge every few hundred T-states, the AY gets each frame's eight registers many times over.

The tune, rendered first

Playing a tune takes a different time every frame, and a loader can't afford that. So the loader first runs the game's own music player 640 times, frame by frame, and keeps the eight register values of each: the introduction, then the first section, looping. Writing them out is then the same work every time.

How it was checked

Checked by shardtape.js through our emulator's tape deck: 503,823 AY writes, each its register's value in the current frame; the loading screen whole while the game loads; the game byte for byte.

Load it yourself

For the 128K. The .tzx and the .tap hold the same tape.

shardstorm-128k-music.tzx, 32 KB, built 11 November 2026
shardstorm-128k-music.tap, 32 KB, built 11 November 2026

Download the .tzx 32 KBDownload the .tap 32 KB
  1. In an emulator (ZX Spin, Retro Virtual Machine, Fuse and others): choose the machine the demo says - a 128K or +2 for the 128K ones - and open the .tzx or the .tap. They hold the same blocks; use whichever your emulator prefers. On a 128K, pick Tape Loader; on a 48K, type LOAD "".
  2. Switch off instant and fast loading. The custom loaders read the tape signal themselves, edge by edge: an emulator that skips the tape skips the loader, and everything it does while it loads.
  3. On a real Spectrum: play the .tzx into the EAR socket from a TZX player. These are for the original machines' timing: the 48K, the 128K and the grey +2.

Borders & Loaders is a set of experiments for the ZX Spectrum, written in Z80 assembly with our own assembler and emulator, and checked frame by frame before anything goes into a game. Made in the UK, by the maker of games for the ZX Spectrum Next.

Shardstorm, the game on the loader demos' tapes, is our own rock shooter in progress. Everything here is our own code, fonts, tunes and pictures. Text in Geist, under the SIL Open Font License.
