# Borders & Loaders

The site at https://mikeynma.github.io/borders-and-loaders/: border effects and custom tape loaders for the ZX
Spectrum, each demo with its tape, screenshots and a page on how it works.

Generated: edit `sitegen/demos.js` in the source repository and run
`node sitegen/make.js`. Videos go in `videos/<demo id>.mp4`.
